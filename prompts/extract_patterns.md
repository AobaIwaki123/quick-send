# パターン抽出プロンプト

以下のデータセットを分析し、共通するパターンを詳細に抽出してください。

## 分析対象のデータ

```
{examples}
```

## タスク

1. **パターンの抽出**: 上記の文章に共通する特徴を詳細にリストアップ
2. **具体例の引用**: 各パターンを示すデータからの具体例を含める（要約しない）
3. **強度の評価**: 各パターンがどの程度顕著かを評価

## 重要な指示

- **要約しない**: データから観察されるすべての特徴を網羅的に抽出すること
- **具体例を必ず含める**: 各パターンに対して、元データからの引用例を複数含める
- **解像度を最大化**: 曖昧な表現を避け、具体的な言語特徴を指摘する

## 出力形式

```json
{{
  "patterns": [
    {{
      "id": "pattern_1",
      "name": "パターン名",
      "category": "lexical|syntactic|semantic|structural",
      "description": "パターンの詳細な説明",
      "strength": "strong|medium|weak",
      "frequency": 0.0-1.0,
      "examples": [
        "データから抽出した具体例1",
        "データから抽出した具体例2"
      ],
      "detection_rule": "このパターンを検出するための具体的な基準"
    }}
  ]
}}
```

## 分析の観点

### 表層的特徴 (lexical)
- 語彙の選択 (頻出する単語・フレーズ)
- 文体・口調 (丁寧語、敬語、口語)
- 接続詞や転換表現

### 構造的特徴 (structural)
- 箇条書きや番号付けの有無
- 段落構成
- 情報の展開方法

### 構文的特徴 (syntactic)
- 文の長さや複雑さ
- 文末表現のパターン
- 受動態・能動態の使用

### 意味的特徴 (semantic)
- 抽象度 (具体例の有無)
- 主張の明確さ
- 感情表現の程度
