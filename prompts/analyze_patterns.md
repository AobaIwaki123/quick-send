# パターン比較・分析プロンプト

以下の2つのパターンリストを比較し、ユーザーへの改善アドバイスを生成してください。

## 入力データ

### AI感があるとされた文章のパターン
```json
{bad_patterns}
```

### 良いとされた文章のパターン
```json
{good_patterns}
```

## タスク

1. **比較分析**: 2つのパターンリストの差異を特定する
2. **改善アドバイス**: ユーザーが「AI感」を避けるための具体的な助言を作成する
3. **優先順位付け**: 最も効果的な改善ポイントを特定する

## 重要な指示

- **パターンリスト自体は出力しない**: `comparison` と `advice` のみを生成すること
- **具体的な改善策を提示**: 「〜を避ける」だけでなく「代わりに〜を使う」のような建設的な提案をする
- **入力データを参照**: 分析は入力されたパターンリストに基づいて行う

## 出力形式

```json
{{
  "comparison": {{
    "key_differences": [
      "AI感がある文章と良い文章の主な違い1",
      "AI感がある文章と良い文章の主な違い2"
    ],
    "overlapping_features": [
      "両方に共通する特徴（あれば）"
    ],
    "critical_indicators": [
      "AI感を判断する上で最も重要な指標"
    ]
  }},
  "advice": {{
    "priority_improvements": [
      {{
        "rank": 1,
        "title": "最優先の改善ポイント",
        "problem": "具体的な問題",
        "solution": "具体的な解決策",
        "before_example": "改善前の例",
        "after_example": "改善後の例"
      }}
    ],
    "general_tips": [
      "一般的なアドバイス1",
      "一般的なアドバイス2"
    ],
    "summary": "改善のための全体的なまとめ"
  }}
}}
```
