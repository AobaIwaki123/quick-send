## 加工後: Memos投稿用フォーマット

```markdown
# 📚 文章改善ガイド

## ⚠️ 避けるべきパターン (AI感)

### 1. 過度な丁寧語の使用
「させていただく」「存じます」などの過剰な敬語表現が頻出

**具体例:**
- ご説明させていただきます
- ご確認いただければ幸いに存じます
- お伝えさせていただきたく存じます

---

### 2. 箇条書きの多用
情報を過剰に構造化し、箇条書きで列挙する傾向

**具体例:**
- 以下の点が重要です： - 点A - 点B - 点C
- メリットは次の通りです： 1. 効率化 2. コスト削減

---

## ✅ 良いパターン

### 1. 簡潔な口語表現
「〜ですね」「〜かな」など自然な語尾を使用

**具体例:**
- これ、いい感じですね
- ちょっと確認してみますね
- たぶん大丈夫だと思う

---

## 🔧 改善アドバイス

### 最優先: 敬語を減らす
**問題:** 「させていただく」の多用
**解決策:** 「します」「しますね」に置き換え

| Before                   | After        |
| ------------------------ | ------------ |
| ご報告させていただきます | 報告しますね |

### 一般的なTips
- 箇条書きより文章で説明する
- 「です・ます」の語尾にバリエーションを持たせる

---

**まとめ:** 形式的な敬語を減らし、会話調の自然な表現を心がけましょう。

#learn #writing_guide
```

---

## フォーマット設計方針

| 項目             | 方針                             |
| ---------------- | -------------------------------- |
| **見出し**       | 絵文字+マークダウンで視認性UP    |
| **具体例**       | 必ず箇条書きで提示（最大3件）    |
| **Before/After** | テーブル形式で対比を明確に       |
| **区切り線**     | パターン間で `---` を使用        |
| **タグ**         | `#learn` `#writing_guide` を付与 |

## パターン表示数制限

- **ai_bad**: 最大5パターン
- **good**: 最大3パターン  
- **examples**: 各パターン最大3件
- **priority_improvements**: 最大3件
